Code repository for:

Robinson AK, Shatek SM, Grootswagers T (2026). Sustained multidimensionality of object representations as a scaffold for diverse behaviours.

Preprint DOI TBD.

300 object stimuli: linking EEG with 12 different behavioural tasks

EEG data: www.doi.org/10.18112/openneuro.ds004018.v2.0.0
Previously described in Grootswagers, Robinson & Carlson (2019) The representational dynamics of visual objects in rapid serial visual processing streams. NeuroImage, 188
Images presented at 5 Hz (200 ms per image, no gap between images) while participants looked for targets (stars or boats). All analysed images were non-targets.

Behavioural tasks:
Detection
Orientation
Colourfulness
Curvature
Familiarity
Animacy
Real-world size
Human similarity
Human appearance
Human experience
Similarity
Similarity (speeded)
